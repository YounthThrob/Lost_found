# Civic Ledger

秩序不是冷漠的网格，而是让每一次判断留下可追溯边界的空间。画面以档案纸、索引线、编号与留白构成稳定骨架，模块像被谨慎装订的记录页，彼此保持明确距离。信息通过空间层级被阅读：风险靠近视线，证据保持完整，次要动作退到边缘。最终作品必须像经历无数次校准，以顶级设计师对比例和秩序的深刻理解精密完成。

颜色承担语义而不是装饰。深松绿代表可信与已确认，琥珀色提示待判断状态，矿物红仅用于不可逆或高风险操作，暖纸灰承载长期阅读。色彩面积严格节制，微小的状态点、标签和边线即可改变阅读路径；每一次色值选择都应显得经过 painstaking attention，呈现大师级的克制与准确。

尺度形成节奏：宽阔的工作台承载密集记录，狭窄的索引栏维持方向感，巨大但低声的序号建立章节感。表格不是数据仓库，而是连续的证据带；表单不是孤立卡片，而是具备前提、影响和确认边界的操作仪器。所有对齐、分栏与间距都要像经过数百次微调，体现深厚经验与 meticulous craftsmanship。

文字只承担必要标记。中文负责行动语义，窄体拉丁字与等宽数字负责编号、时间和系统状态；长解释被压缩为短句，信息主要由位置、密度、颜色和形状传达。字体层级应像精密仪表一样安静可靠，任何字符都不得拥挤或漂移，呈现耗费无数小时打磨的专业完成度。

构图在理性与人性之间保持张力。严格网格允许局部圆角、纸张阴影和柔和光晕，使高风险运营工具依然具备触觉温度；少量轨迹线与索引符号暗示物品从丢失、发现到归还的隐秘路径。最终视觉必须是完整的艺术对象，也是一套可信的工作环境——由行业顶尖创作者以 master-level execution 逐像素雕琢而成。
