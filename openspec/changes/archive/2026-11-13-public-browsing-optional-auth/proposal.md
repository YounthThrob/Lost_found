# 公开浏览与可选登录（public-browsing-optional-auth）

## 背景

当前所有接口（除微信登录与静态图片外）都强制登录，小程序启动即被重定向到登录页。这违背用户对「先逛再看、需要操作时再登录」的普遍预期：用户希望打开小程序就能浏览招领/寻物信息，只有在发布、认领、收藏等写操作时才被要求登录。

## 目标

- 将三个只读端点开放为公开（匿名可访问）：`GET /posts`（搜索列表）、`GET /posts/{postId}`（详情）、`GET /stats`（统计）。
- 这三个端点支持**可选登录**：提供有效令牌时按需使用，缺失或无效令牌时一律视为匿名，绝不返回 401。
- 其余写操作与 `/me/*`、`/admin/*` 端点鉴权不变，未登录仍返回 401 `SESSION_EXPIRED`。
- 小程序改为「先逛后登录」：首页为默认入口，写操作（发布/认领/线索/收藏等）才触发登录；登录页增加协议勾选，协议文本可点击查看全文。

## 非目标

- 不在公开端点上做个性化返回（如「我是否已收藏」）；有效令牌仅用于保持既有语义（作者可见草稿详情），不新增个性化字段。
- 不调整公开信息的可见范围（仍为 PUBLISHED/VERIFYING），非公开状态详情继续返回 404。
- 不引入新错误码、不改状态机。
